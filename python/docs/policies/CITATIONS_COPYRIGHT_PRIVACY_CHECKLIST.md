# DATA120 — Sources, Copyright, and Data Privacy Checklist

## A. Sources / APA

For every externally sourced dataset, idea, statistical method, copied/adapted snippet, image, or figure:
1. Record the creator, date, title, link/DOI, and license/access terms.
2. Add a citation adjacent to the relevant claim, chart, method, or snippet.
3. Add a matching entry in the report's References section; use the instructor's specified format (APA is recommended in the supplied course material).
4. Cite reused personal work as required. Keep AI attribution separate where prescribed, and follow UCalgary instructions for citing GAI.
5. Verify every reference; AI-generated bibliographic details can be fabricated.

Start here: https://owl.purdue.edu/owl/research_and_citation/apa_style/apa_style_introduction.html

## B. Copyright

- [ ] I own, have permission for, or otherwise have a lawful basis to distribute each file.
- [ ] I have not uploaded restricted lecture content or peer submissions.
- [ ] Each third-party dataset or chart has been reviewed for its actual license.
- [ ] I know that a citation alone does not authorize copying or public release.

UCalgary Copyright Office: https://library.ucalgary.ca/copyright

## C. ParkingPatrol project privacy

This is a **public GitHub repository**. The Google Form/Sheet workflow may contain actual licence plates and timestamps, which can create sensitive linkage and re-identification risks.

- [ ] No real licence plate or name is committed, even in screenshots, notebooks, fixtures, logs, or Git history.
- [ ] No source Sheet export, row-level operational data, credentials, tokens, or service-account files are committed.
- [ ] Public examples use synthetic data; any aggregates are reviewed for disclosure risk.
- [ ] A separate, access-controlled working location holds approved data, if real-data analysis is authorized.
- [ ] Pseudonymous IDs are created with a protected keyed process; no lookup table/key is public.
- [ ] Dataset access and retention match applicable business obligations and approved course scope.
- [ ] No peer's or customer's private data is uploaded to GAI without necessary authorization.
- [ ] Publication and submission are assessed **separately**: confidential instructor submission does not imply permission to publish source data on GitHub.

## D. Responsible ML

- [ ] No inference claims that repeated presence proves non-customer parking.
- [ ] No invented arrival/departure or continuous parking duration.
- [ ] Observation coverage and incomplete checks are accounted for.
- [ ] AI/rule-generated flags are not treated as independent true offender labels.
- [ ] Models are evaluated against an appropriate baseline and with a time-based test set where applicable.
- [ ] No tickets or towing are automatically triggered by model outputs.
